                            FUNCIONAMENTO
================================================================================

FLUXO PRINCIPAL:
┌─────────────────────────────────────────┐
│ 1. Ler fuel-level do sensor             │
├─────────────────────────────────────────┤
│ 2. Verificar condições:                 │
│    - fuel >= 300 E jóias em memória?    │
│      → Propor GET-JEWEL                 │
│    - fuel < 300 E comidas em memória?   │
│      → Propor EAT-FOOD                  │
│    - Nenhum dos acima?                  │
│      → Propor WANDER                    │
├─────────────────────────────────────────┤
│ 3. Selecionar operador por prioridade   │
├─────────────────────────────────────────┤
│ 4. Executar subgoal correspondente      │
└─────────────────────────────────────────┘

OPERADORES:

[A] WANDER (Prioridade 1 - Fallback)
    ├─ Sempre disponível
    ├─ Faz robô girar: VelR=3, VelL=0
    ├─ Items visuais são armazenados em memória
    └─ Estrutura: SCANNING-ITEMS.{JEWELS|FOODS}.list

[B] GET-JEWEL (Prioridade 10 - Alta)
    ├─ Acionado quando: fuel >= 300 E há jóias em memória
    ├─ Busca jóia mais próxima em SCANNING-ITEMS.JEWELS
    ├─ Move-se para (x, y) da jóia
    └─ Executa GET quando distância < 30 unidades

[C] EAT-FOOD (Prioridade 9 - Média-Alta)
    ├─ Acionado quando: fuel < 300 E há comidas em memória
    ├─ Busca comida mais próxima em SCANNING-ITEMS.FOODS
    ├─ Move-se para (x, y) da comida
    └─ Executa EAT quando distância < 30 unidades

ESTRUTURA DE MEMÓRIA CRIADA:
```
CREATURE
├── SENSOR
│   ├── FUEL.VALUE
│   └── VISUAL.ENTITY[] (items visíveis agora)
│
├── POSITION (X, Y)
├── PARAMETERS
├── MEMORY
│
└── SCANNING-ITEMS ← NUEVA ESTRUTURA
    ├── JEWELS
    │   └── list[] (items encontrados)
    │       ├── item-name: "JEWEL_1"
    │       ├── item-x: 100.0
    │       ├── item-y: 150.0
    │       └── item-color: "red"
    │
    └── FOODS
        └── list[] (items encontrados)
            ├── item-name: "FOOD_1"
            ├── item-x: 200.0
            ├── item-y: 100.0
            └── item-color: "green"
```

                          COMO USAR
================================================================================

1. COMPILAR:
   $ cd /home/nicolas/Programas/DemoJSOAR
   $ ./gradlew build -x test

2. EXECUTAR:
   $ ./gradlew run
   (Ou abrir no IDE com Main.java)

3. OBSERVAR NO MindView:
   - Campo "current-subgoal": Vê operador selecionado
   - INPUT LINK: Items visíveis agora
   - Campo "SCANNING-ITEMS": Items armazenados em memória
   - Campo "fuel-level": Combustível atual

4. INTERPRETAR COMPORTAMENTO:
   - Robô girando? → WANDER ativo
   - Robô em movimento? → GET-JEWEL ou EAT-FOOD
   - Items em SCANNING-ITEMS crescendo? → Memory funcionando
